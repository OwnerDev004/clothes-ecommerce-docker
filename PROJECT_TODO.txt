PHASE 1.4 - CHECKOUT + ORDER CREATION
Goal:
- Safely create orders and prevent overselling.
Tasks:
- Re-validate stock at checkout (do not trust cart snapshot).
- Compute subtotal/discount/shipping/total on server only.
- Create order + order_items in one DB transaction.
- Decrease stock atomically (stock-safe query).
- Save price snapshot in order_items.
Deliverable:
- Checkout endpoint that creates correct order records and updates stock.
Done check:
- Two simultaneous checkouts cannot push stock below zero.

Tasks:
- Add create payment intent/session endpoint.

- Map payment events to order status changes.
- Handle failed/expired payments safely.
Deliverable:
- Payment flow that updates order status automatically.
Done check:
